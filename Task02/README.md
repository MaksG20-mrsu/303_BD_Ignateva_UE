# Task02. ETL скрипт для SQLite

## Требования к окружению
Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:
- Python версии 3.x
- SQLite3

## Запуск
1. Убедитесь, что исходные файлы (`movies.csv`, `ratings.csv`, `tags.csv`, `users.txt`) находятся в папке `dataset`.
2. Запустите скрипт `db_init.bat`.
3. В результате будет сгенерирован файл `db_init.sql` и создана база данных `movies_rating.db` с загруженными данными.
